Benchmark your model in five minutes

Any learner works: PyTorch, scikit-learn, or a plain function. The data and the score are those of the paper.

  1. 1Install

    git clone https://github.com/Zhou-Hangyu/lewi-code.git
cd lewi-code
pip install --upgrade pip
pip install -e .

    Python 3.10 or later on Linux, macOS or Windows (WSL); about 1.5 GB of disk, most of it PyTorch; no GPU. A C++ compiler makes LeWi's training faster.

  2. 2Develop your learner on a development instance

    import csfrbench, torch

def my_fit(X, y, X_val, y_val):          # any learner
    X, y = torch.tensor(X), torch.tensor(y)
    net = torch.nn.Sequential(
        torch.nn.Linear(X.shape[1], 64), torch.nn.ReLU(),
        torch.nn.Linear(64, 1), torch.nn.Flatten(0))
    opt = torch.optim.Adam(net.parameters(), 3e-3)
    for _ in range(2000):
        i = torch.randint(len(y), (32,))
        loss = ((net(X[i]) - y[i]) ** 2).mean()
        opt.zero_grad(); loss.backward(); opt.step()
    return net

task = csfrbench.task("depth4_tree", instance=6016,
                      n=1024)            # development
model = my_fit(task.X_train, task.y_train,
               task.X_val, task.y_val)
print(task.evaluate(model))              # test NMSE

  3. 3Compare once, on an evaluation instance

    curve = csfrbench.learning_curve(my_fit, "depth4_tree",
                                 instance=6000)  # 7 sizes
csfrbench.compare([curve])  # beside the paper's methods

Tune on instances 6016–6019; report on 6000–6015. The evaluation instances (and 6020–6035 of the sampled DAGs) give the numbers you report: run them once, with your final learner, and never use them to choose its settings. The recorded methods trained for 64,000 steps and kept the best of 32 configurations, so quick-interface results are exploratory; the protocol gives numbers you can put beside the paper's. The whole example as one script: examples/quickstart.py.

Eight target families

The families span different computational structures: hierarchy, intermediate reuse, independent modules and varying graph topology. Every local function reads two values, except the high-arity node, which reads all eight inputs at once.

Two settings

Primary, setting="primary": every input is active, d=8d = 8d=8 (16 on the depth-5 tree).

Nuisance inputs, setting="nuisance": the same targets with inert inputs added to reach d=32d = 32d=32: 24 for the eight-input targets, 16 for the depth-5 tree. The learner must also find which inputs matter.

Your learner sees examples. The benchmark keeps the graph.

The graph never reaches the learner. It stays behind for two uses that make the benchmark more than a leaderboard.

Your learner gets

  • nnn noisy training examples, n=29,…,215n = 2^9, \dots, 2^{15}n=29,…,215, nested across sizes
  • 4,096 noisy validation examples, for model selection
  • nothing else: no graph, no active inputs, no intermediate values

The benchmark keeps

  • Graph-informed references. GraphOracle networks are wired like the target, one to all levels deep; they show how much sample efficiency the structure is worth.
  • Structural evaluation. Linear probes, counterfactual interventions and unit associations show whether a learner's layers and wiring follow the target's computation.
target = task.reveal()       # after training
target.graph.node_parents    # the graph
target.intermediates(X)      # every intermediate

Hidden by protocol, not by access control. task.reveal() works at any time, so nothing stops a learner from reading the target. Using the graph, the active inputs or the intermediate values while training breaks the protocol; only the graph-informed references read them.

Quick to try, strict to report

The score is the test NMSE on noise-free inputs, summarized over training-set sizes by the area under the learning curve.

Reproduce the paper

The package holds the records of every training run. A run of the per-network trainer equals its record bit for bit in the records' environment; LeWi and Dense also train in fast stacks whose results agree with the records statistically, not digit by digit.

csfrbench verify                                  # 4 minutes: the installation against the records
csfrbench record --setting primary                # the paper's AULC table
csfrbench reproduce --workload depth4_tree --arms lewi dense --out runs/repro --workers 8
csfrbench plan --setting primary --workloads depth4_tree --out units.jsonl
csfrbench run --units units.jsonl --out runs/tree --workers 24
csfrbench analyze --runs runs/tree

Every figure and table of the paper, with its command and compute: docs/REPRODUCE.md. The full definition: docs/SPEC.md.
